# Asset provenance

## Original frontend captures

- `projects/studymind/home.webp` and `auth.webp`: original public [StudyMind React frontend](https://github.com/Hazmat-ai/StudyMind/tree/main/frontend), captured locally at 1440 × 1000. Empty workspace and actual sign-in route; no seeded study material or model output.
- `projects/campaign-os/home.webp` and `brief.webp`: original HomeScreen and InputScreen components from [Campaign-app](https://github.com/Hazmat-ai/Campaign-app/blob/main/index.html), rendered locally in Chrome. Original markup, styles and fonts retained. Empty brief, no API call or generated campaign. These captures do not establish a working backend or live deployment. The preserved portfolio describes the Claude version while the current source uses Gemini; the owner should confirm the version before changing project facts.
- `projects/asl-recognition/home.webp`: original public [ASL frontend](https://github.com/Hazmat-ai/ASL_Recognition), captured locally at 1440 × 1000 with the camera inactive. No simulated recognition results.

Original source repositories and their licenses remain authoritative.
